Entry for the make.fun bounty [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949): the one sentence a house cat would say in its own defence in the five seconds after knocking a glass off the table.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`:

> That glass was squatting in my sunbeam since three o'clock, so I evicted it.

No apology, no confession — just the most convincing case a cat can make: the glass was the trespasser.
